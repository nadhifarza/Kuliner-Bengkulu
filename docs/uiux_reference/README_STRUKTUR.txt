KULINER BENGKULU — UI/UX SVG TERPISAH

Struktur folder:
01_DESKTOP/     Berisi 48 layar khusus desktop, berurutan 01–48.
02_MOBILE/      Berisi 48 layar khusus mobile, berurutan 01–48.
00_DOKUMENTASI/ Indeks CSV, peta urutan, dan panduan.

Cara penggunaan:
1. Ekstrak ZIP.
2. Buka folder 01_DESKTOP untuk melihat seluruh desain desktop secara berurutan.
3. Buka folder 02_MOBILE untuk melihat seluruh desain mobile secara berurutan.
4. Nomor pada nama file menghubungkan pasangan layar desktop dan mobile.

Contoh:
01_login_desktop.svg  <-> 01_login_mobile.svg
02_registrasi_desktop.svg <-> 02_registrasi_mobile.svg

Total: 48 layar inti x 2 platform = 96 file SVG.
Logo, palet warna, dan tipografi mengikuti panduan desain Kuliner Bengkulu.
